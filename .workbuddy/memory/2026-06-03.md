## 扩大 import_csv 列名匹配范围

### 修改文件
- `main.py`：`EditCategoryDialog.import_csv()` 表头匹配逻辑

### 变更说明
原来使用精确等号匹配列名（`col == '代码'`），现改为关键字包含匹配（`k in col_lower`），各列支持的别名如下：

| 列 | 支持的列名关键字 |
|----|----------------|
| 代码 | 代码、股票代码、证券代码、code、symbol、ticker |
| 名称 | 名称、股票名称、证券名称、公司名称、公司简称、简称、name |
| 高位提醒 | 高位涨幅提醒、涨幅提醒、高位提醒、高位、high |
| 低位提醒 | 低位跌幅提醒、跌幅提醒、低位提醒、低位、low |

匹配规则：忽略大小写，只要列名包含关键字之一即命中。
