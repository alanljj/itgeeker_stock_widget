# 2026-06-11 工作日志

## 修改开机自启注册表键名

### 需求
- 将注册表自启键名从 `ITGeeker Stock Widget`（含空格）改为 `ITGeekerStockWidget`（无空格）

### 修改文件
- `main.py`：
  - 新增常量 `AUTO_START_KEY_NAME = "ITGeekerStockWidget"`
  - `is_auto_start_enabled()`：查询新键名，找不到时兼容查询旧键名 `APP_NAME`
  - `set_auto_start(True)`：写入新键名，同时删除旧键名避免残留
  - `set_auto_start(False)`：同时删除新旧两个键名

### 兼容性处理
- 开启自启时自动清理旧键名，防止注册表残留
- 关闭自启时同时删除新旧键名
- 检测状态时优先新键名，兼容旧键名
- `APP_NAME` 保持不变，仍用于窗口标题、托盘提示等 UI 显示
