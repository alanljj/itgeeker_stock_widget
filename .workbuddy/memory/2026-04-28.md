# 2026-04-28 工作日志

## 导入/导出 CSV 路径与文件名优化

### 需求 1 - 默认路径改为真实下载目录的子目录
- 新增 `get_export_dir()` 函数
- 通过 `winreg` 读取注册表键 `User Shell Folders\{374DE290-123F-4565-9164-39C4925E467B}` 获取真实下载路径（支持 OneDrive 下载目录等非标准路径）
- `os.path.expandvars()` 展开路径中的环境变量（如 %USERPROFILE%）
- fallback：`~/Downloads`
- 子目录 `ITGeekerWidgetExport` 自动创建（`os.makedirs(exist_ok=True)`）
- 导入/导出对话框默认打开此目录

### 需求 2 - 导出文件名带分组名+时间戳
- 格式：`stock_list_{分组名}_{yyyyMMdd}_{HHmmss}.csv`
- 例：`stock_list_港股_20260425_094512.csv`
- 分组名来自 `self.category_data.get('name', '未命名')`
- 时间戳：`datetime.datetime.now().strftime("%Y%m%d_%H%M%S")`

## 分组widget右键菜单增加「打开主面板」

- `StockWidget.__init__` 新增参数 `show_main_callback=None`
- `contextMenuEvent` 新增「打开主面板」菜单项（在分隔符上方，置顶/关闭之前）
- `ControlPanel` 新增 `_show_main_panel()` 方法（`self.show(); raise_(); activateWindow()`）
- `open_widget()` 创建 `StockWidget` 时传入 `show_main_callback=self._show_main_panel`
