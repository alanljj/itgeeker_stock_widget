# 2026-05-30 工作日志

## 新增交易时段判断（非交易时段不拉取数据）

### 修改文件
- `data_service.py`：新增 `is_trading_time()` 函数 + 节假日表 `CN_HOLIDAYS` + 调休补班表 `CN_EXTRA_TRADING_DAYS`
- `stock_widget_window.py`：`fetch_data()` 开头调用 `is_trading_time()`，非交易时段直接 return
- `main.py`：`check_alerts()` 开头同样加交易时段判断

### 逻辑规则
- 交易时段：周一至周五 09:30-11:30 / 13:00-15:00
- 周末 → 不交易（除非在调休补班表中）
- 节假日 → 不交易（维护 CN_HOLIDAYS 集合）
- 调休补班周末 → 交易（维护 CN_EXTRA_TRADING_DAYS 集合）
- 节假日表已覆盖 2025 全年 + 2026 全年，每年初需更新

### 测试结果
全部 9 个用例通过，当前时间（周六）正确返回 False

## Widget 标题右侧增加市场状态/最后拉取时间显示

### 修改文件
- `data_service.py`：新增 `get_market_status()` 函数，返回：交易中→空串、未开盘/午休/已收盘/周末休市/节假日
- `stock_widget_window.py`：
  - `import datetime` 头部新增
  - `import get_market_status` 导入
  - 新增 `self.last_fetch_time = None` 字段
  - `fetch_data()` 成功后记录 `self.last_fetch_time`，非交易时段也触发 `self.update()` 刷新状态文字
  - `paintEvent` 标题右侧绘制：交易中显示 HH:MM:SS（绿色），非交易时段显示状态文字（灰色）

### 显示逻辑
- 交易时段 & 已拉取过数据：绿色 "14:32:05"
- 交易时段 & 尚未拉取：黄色 "拉取中..."
- 非交易时段：灰色 "周末休市" / "节假日" / "未开盘" / "午休" / "已收盘"

## 修复：非交易时段启动显示空白 → 恢复缓存数据

### 问题
- 非交易时段启动时 `fetch_data()` 直接 return，`self.stock_data` 保持空列表，Widget 显示空白

### 修改文件
- `stock_widget_window.py`：
  - 头部新增 `import os`、`import json`、定义 `_CACHE_DIR`
  - 新增 `_cache_path()`、`_load_cache()`、`_save_cache()` 三个私有方法
  - `__init__` 中在 `fetch_data()` 之前先调用 `_load_cache()` 恢复上一次数据
  - `fetch_data()` 成功拉取后调用 `_save_cache()` 持久化

### 缓存策略
- 缓存路径：`~/itgeeker_widget_config/cache/{分组名}.json`
- 缓存内容：`stock_data` + `last_fetch_time`
- 每个分组独立缓存，互不干扰
- 启动时无论是否交易时段，先加载缓存显示旧数据；交易时段内正常刷新覆盖
